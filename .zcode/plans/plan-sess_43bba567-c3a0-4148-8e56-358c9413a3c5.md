## 二、adapter 包：gorm 钩子 + 生命周期管理器

**hooks.go（新文件）**：包级 observer（atomic.Value 存 func()），setConfigObserver / notifyConfigChanged（非阻塞，未注册忽略）。OneBotConfig 挂 AfterCreate/AfterUpdate/AfterDelete 三个钩子触发通知。注释注明：批量 Update 不带主键不触发钩子，更新必须带主键

**runtime.go（重写 AdapterRuntime）**：
```go
type MessageHandler func(ctx context.Context, msg common.Message)
type NoticeHandler  func(ctx context.Context, ev onebot.UnionEvent)
type AdapterRuntime struct {
    mu sync.Mutex; db *gorm.DB; adapter *onebot.Adapter; cfg OneBotConfig
    hmu sync.RWMutex; msgHandlers []MessageHandler; noticeHandlers []NoticeHandler
    notify chan struct{}; done chan struct{}
    ctx context.Context; cancel context.CancelFunc
    wg sync.WaitGroup; started bool
}
```
API：NewAdapterRuntime(db) / Setup(ctx)（AutoMigrate + 空表插默认行 :8080 未启用）/ Start()（注册 observer → reconcileLoop → 首次 reconcile）/ Stop()（幂等：close(done) → Stop adapter → cancel → wg.Wait）/ reconcile（读配置→对比快照→无变 no-op / 有变 Stop 旧 + Enable=true 则 New+Start+pump）/ Reload() / SetEnabled(ctx, bool)（First→改→Save，运行时开关）/ UpdateConfig(ctx, mutate) / GetStatus() / OnMessage(h) / OnNotice(h)
稳定性：notify 缓冲 1 + 非阻塞发送合并抖动；reconcile 幂等；Setup 自建默认行钩子自发自消

**handler.go（空壳启用）**：MessageHandler/NoticeHandler 类型；每 adapter 实例一个 pump goroutine（select inbound/notices/退出），逐个同步调用 handler（带 recover），ctx 传 runtime 根 ctx

**runtime_test.go（新）**：依赖真实 PG（环境变量 DSN，无则 t.Skip）：建表+默认行；enable 自动启停；改 Addr 重建；Delete 行自愈为默认配置
